# 🎨 PROMPTS PARA CRIAR ICONE DO PROF CONTROLLER

## 📱 O QUE É PROF CONTROLLER?

**ProF Controller** é um aplicativo web moderno de gestão patrimonial financeira. É uma plataforma completa para:
- 💰 Controlar e monitorar patrimônio (investimentos, contas, ativos)
- 📊 Visualizar dados financeiros com gráficos interativos (Chart.js)
- 🔐 Gerenciar segurança com autenticação (Face ID, biometria)
- 📱 Funcionar como Progressive Web App (PWA)
- 🌍 Suportar múltiplas moedas e idiomas
- 💳 Sistema de subscrição (planos pro/premium)

**Estilo Visual:**
- Design moderno com glassmorphism
- Paleta: Azul (#0099FF), Verde (#00D77E), Laranja (#FF6B35), Amarelo (#FFB800)
- Interface dark mode profissional
- Animações suaves e efeitos modernos

---

## 🎯 ESPECIFICAÇÕES TÉCNICAS

### Tamanhos Necessários:
- **192x192 pixels** - PWA icon (primário)
- **512x512 pixels** - PWA splash screen
- **180x180 pixels** - Apple iOS (opcional)

### Proporções:
- **Quadrado 1:1** (não retângulo)
- **Margem/Padding:** mínimo 10% de cada lado
- **Resolução:** 300 DPI para qualidade print

### Cores (RGB):
- **Azul Primário:** RGB(0, 153, 255) / #0099FF
- **Verde Secundário:** RGB(0, 215, 126) / #00D77E
- **Laranja Terciário:** RGB(255, 107, 53) / #FF6B35
- **Amarelo Ouro:** RGB(255, 184, 0) / #FFB800
- **Fundo Dark:** RGB(10, 14, 39) / #0A0E27

OPCOES DE INSTALACAO (Escolha Uma):
================================================================================

OPCAO 1 - MAIS RAPIDA (2 minutos):
  1. Va para: https://github.com/ferpa2505-art/prof-controller/releases/tag/v1.0.0
  2. Clique: "Download ZIP"
  3. Extraia o arquivo
  4. Clique duplo em: index.html
  ✅ App abre no navegador!

OPCAO 2 - PARA DESENVOLVEDORES (Terminal):
  git clone https://github.com/ferpa2505-art/prof-controller.git
  cd prof-controller
  git checkout v1.0.0
  python -m http.server 8000
  Abra: http://localhost:8000

OPCAO 3 - SEM INSTALACAO (Em breve):
  Acesse: https://prof-controller.github.io

TESTES RAPIDOS (2 Minutos):
================================================================================

Quando app abrir, teste:
  ✓ Logo sem borda branca (canto superior esquerdo)
  ✓ Cambio mostra 2 ultimos dias + setas (📈📉→)
  ✓ Proventos padrao em "A confirmar" (Investimentos → Proventos)
  ✓ Acoes com toggle +/- (Tabela Investimentos → coluna Acoes)
  ✓ Painel de atualizacao (Preferencias → Avancado)
  ✓ NAV Grafico padrao em "Conta/Bem" (Investimentos → Grafico)

TROUBLESHOOTING RAPIDO:
================================================================================

Pagina em branco?
  → Ctrl+Shift+Delete (limpar cache)
  → Feche e reabra navegador

Nao consegue conectar?
  → Certifique-se que servidor esta rodando
  → python -m http.server 8000

Notificacoes nao funcionam?
  → Preferencias → Notificacoes
  → Clique "Permitir Notificacoes"

Para mais problemas, veja GETTING_STARTED.md → Troubleshooting

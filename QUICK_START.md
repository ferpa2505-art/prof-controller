# 🚀 ProF Controller v1.0.0 - Quick Start (3 Minutos)

## ⚡ Instalação Rápida

### **Windows/Mac/Linux**

```bash
# 1️⃣ Clone o repositório
git clone https://github.com/ferpa2505-art/prof-controller.git
cd prof-controller

# 2️⃣ Checkout da versão 1.0.0
git checkout v1.0.0

# 3️⃣ Inicie servidor local
python -m http.server 8000

# 4️⃣ Abra no navegador
# http://localhost:8000
```

**Pronto! ✅ App rodando em 30 segundos**

## 📞 Problema?

### **Página em branco?**
```
1. Pressione: Ctrl+Shift+Delete (limpar cache)
2. Recarregue: Ctrl+R ou Cmd+R
```

### **Dados não carregam?**
```
1. Abra DevTools: F12
2. Vá para aba: Console
3. Procure por erros vermelhos
```

### **Notificações não funcionam?**
```
1. Vá para: Preferências → Notificações
2. Clique: "Permitir Notificações"
3. Autorize no prompt do navegador
```

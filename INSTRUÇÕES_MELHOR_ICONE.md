## ❓ COMO FAZER O RESIZE?

### Opção 1: Canva (Grátis)
1. Abra a imagem no Canva
2. Clique "Redimensionar"
3. Digite 192x192
4. Exporte como PNG
5. Repita para 512x512

### Opção 2: Photoshop
1. File > Open
2. Image > Image Size
3. Digite 192x192 (ou 512x512)
4. Resample: Bicubic Sharper
5. Export as PNG

### Opção 3: Online (Grátis)
https://www.iloveimg.com/resize-image
- Upload da imagem
- Resize para 192x192
- Download
- Repita para 512x512

### Opção 4: Python (Automático)
Se eu receber os arquivos e forem do tamanho errado, eu mesmo faço o resize!

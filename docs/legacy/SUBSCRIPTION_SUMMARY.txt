❓ DÚVIDAS FREQUENTES
───────────────────────────────────────────────────────────────────────────────

P: Por que Stripe e não outra plataforma?
R: Stripe tem melhor relação custo/benefício, suporta múltiplas moedas,
   oferece webhooks e documentação excelente. Taxa: 2,9% é padrão mercado.

P: Preciso de backend próprio?
R: Sim! É necessário para:
   - Validar tokens de autenticação
   - Gerenciar seriais únicos
   - Processar webhooks de pagamento
   - Enviar emails automáticos

P: Como garantir segurança dos dados de pagamento?
R: Stripe mantém conformidade PCI-DSS. Você NUNCA vê dados de cartão.
   O próprio Stripe processa tudo com segurança.

P: Qual é a melhor opção para App Store/Google Play?
R: RevenueCat integra com ambas e gerencia tudo de forma centralizada.
   Alternative: Implementar Google Play Billing + App Store Server API direto.

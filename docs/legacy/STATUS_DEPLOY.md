## 📞 COMO USAR

### Visualizar em Produção:
```
URL: https://ferpa2505-art.github.io/prof-controller/
Status: ✅ LIVE
```

### Fazer Alterações:
1. Editar CSS em `modern-ui.css` ou `modern-dashboard.css`
2. Editar JS em `modern-dashboard.js`
3. Commit e push (auto-deploy via GitHub Pages)
4. Atualizar cache no navegador (Ctrl+Shift+R)

### Customizar Cores:
```css
/* Em modern-ui.css */
:root {
  --primary: #0099FF;      /* Altere para sua cor */
  --success: #00D77E;
  --danger: #FF4757;
  /* Todas as cores cascateiramente mudam */
}
```

```javascript
// ✅ Use sempre "Portfólio"

// ✅ Use "Drawdown máximo" (híbrido aceito) ou "Queda máxima" (100% PT-BR)

// ✅ Use sempre "Beta"
```

## 📊 Validação de Consistência

### Checklist para Fase 13

- [ ] Todos os termos de portfolio usam **"Portfólio"** (não "Carteira")
- [ ] Todos os retornos de preço usam **"Retorno"** (não "Rendimento")

- [ ] Métricas de Sharpe/Sortino/Beta padronizadas (sem variações)

## 🎯 Recomendações Finais

### 1. **Simplificar para Usuários Não-Técnicos**

```javascript
// ❌ Complexo demais:
"Índice de Sharpe: 1.2"

// ✅ Melhor:
"Eficiência: 1.2 (Alto)"
"Você ganhou 1.2% para cada 1% de risco"
```

### 2. **Adicionar Tooltips Explicativos**

Cada métrica financeira deve ter um tooltip:

```javascript
'metrics.sharpe.tooltip': 'Mede quanto retorno você ganha por unidade de risco. Maior = melhor.',
'metrics.beta.tooltip': 'Mede como seu portfólio varia em relação ao IBOV. 1.0 = igual ao mercado.',
'metrics.sortino.tooltip': 'Como Sharpe, mas penaliza apenas quedas (não subidas). Mais realista para investidores.'
```

### 3. **Glossário Integrado à App**

Criar uma seção de **Ajuda** com glossário dos termos:

```javascript
// Novo arquivo: GLOSSARY.js

    'es': 'Índice de Sharpe: Mide la eficiencia del retorno en relación al riesgo.'

  // ... mais termos

```
